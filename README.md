# NexoNotification

A modern futuristic Android notification manager inspired by Nothing OS, HyperOS, and Dynamic Island UI.

## Features

- Smart Notification Center
- Notification History
- Deleted Notification Recovery
- Dynamic Island Style Popup
- Floating Notifications
- AMOLED Black UI
- Smooth Modern Animations
- App Filters
- Search Notifications
- Quick Actions
  - Reply
  - Copy
  - Save
  - Delete
- Notification Priority System
- RGB Glow Effects
- Modern Glassmorphism Design
- Custom Notification Position
- Notification Timeline
- Lightweight & Fast

---

## UI Style

- Nothing OS Inspired
- Cyberpunk Design
- AMOLED Dark Theme
- Blur Glass Effects
- Rounded Modern Cards
- Dynamic Transitions
- Smooth User Experience

## Tech Stack

- Java / Kotlin
- Android Studio
- Material 3
- NotificationListenerService
- Firebase (Optional)
- Room Database
- Google Drive API (Optional)

## Permissions Used

| Permission | Purpose |
|---|---|
| Notification Access | Read and manage notifications |
| Internet | Cloud sync and AI features |
| Foreground Service | Background notification service |
| Overlay Permission | Floating popup and Dynamic Island |
